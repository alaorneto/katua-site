Produtos

Dois produtos, uma base.

O Skeleton é a fundação aberta que usamos em tudo. O Medvita é o primeiro sistema completo construído sobre ela.

Open source Django · PostgreSQL

Skeleton

A base pronta para sistemas com várias empresas.

Login, organizações, permissões e auditoria já resolvidos. O Skeleton cuida da infraestrutura que todo sistema multiempresa precisa, e o seu projeto cuida só das regras do negócio.

  • Login com senha, SSO e MFA
  • Dados de cada organização isolados no banco
  • Controle de acesso por registro
  • Auditoria e histórico de cada mudança
  • API com tokens e contas de serviço
  • Apps em pacotes assinados, ativadas por organização

Gestão de clínicas Web e Windows

Medvita

A clínica inteira numa tela só.

Agenda, pacientes, prontuário e financeiro para consultórios e pequenas clínicas. Uma secretária virtual conversa com o paciente e marca a consulta, sempre identificada como IA.

  • Agenda por profissional, com encaixes e lista de espera
  • Cadastro de pacientes com busca rápida
  • Prontuário eletrônico
  • Financeiro integrado à agenda
  • Secretária virtual que marca consultas
  • No navegador e no aplicativo para Windows

Como trabalhamos

Entregas pequenas, sempre visíveis.

Você acompanha o sistema crescendo, versão por versão. Cada mudança tem registro, revisão e teste.

  1. 01

    Entender

    Conversamos com quem vai usar o sistema e transformamos o problema em uma lista clara de entregas.

  2. 02

    Prototipar

    Você vê e testa as telas antes do código. Ajustar um protótipo custa minutos.

  3. 03

    Construir

    A IA acelera a escrita e os testes. Pessoas revisam e aprovam cada mudança antes de ela entrar.

  4. 04

    Evoluir

    Cada versão sai com notas do que mudou. O sistema cresce com o seu negócio, sem recomeçar do zero.

issue→branch→pull request→revisão→versão
